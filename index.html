The model

Two models, one question: who wins?

A logistic regression and a random forest were both trained on the same stat sheet: one team's full season minus the other's, drawn from real NFL play-by-play data. Each team's completed season predicts the following season's games — never its own — so the model is never peeking at results it's trying to predict. Logistic regression powers the live predictor above because its weights are easy to inspect; the random forest is shown here for comparison.

Why not higher?

Predicting a season from the season before is a harder problem than it sounds — rosters turn over, coaches change, and last year's numbers only say so much about this year's team. Models that instead use in-season, game-by-game form tend to score higher; this one trades some accuracy for a cleaner, honest test: no stat here was ever generated after the game it's trying to predict.

Reading the scoreboard

The percentage is the home team's chance to win based on the stat gap between the two teams' most recently completed seasons, plus a standard home-field bump. It is not a point-spread or a score prediction — just a probability.

Methodology

Where this data comes from

Every number on this page comes from real NFL play-by-play and schedule data, pulled with nfl_data_py (which wraps the open nflverse data project). The league table below shows each team's actual 2025 season. The model was trained on eleven years of history: every team's completed season, from 2015 through 2024, paired with the games that team played the following year.

This page is a static export — the training run happens once, offline, and its results (team stats and model weights) are baked into this file so the page can run standalone on GitHub Pages with no server or live data pull. To refresh it with a new season, rerun the pipeline and retrain: python nfl_data_pipeline.py pulls the latest play-by-play and schedules, python train_real_model.py retrains and writes model_export_real.json, and that JSON replaces the MODEL object in this page's script.
Built with a logistic regression model on twelve common NFL team stats. Trained on real 2015–2025 NFL data via nfl_data_py.
