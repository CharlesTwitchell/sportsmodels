The model

Two models, one question: who wins?

A logistic regression and a random forest were both trained on the same stat sheet: one team's full season minus the other's, drawn from real NFL play-by-play data. Each team's completed season predicts the following season's games — never its own — so the model is never peeking at results it's trying to predict. Logistic regression powers the picks above because its weights are easy to inspect; the random forest is shown here for comparison.

Why not higher?

Predicting a season from the season before is a harder problem than it sounds — rosters turn over, coaches change, and last year's numbers only say so much about this year's team. Models that instead use in-season, game-by-game form tend to score higher; this one trades some accuracy for a cleaner, honest test: no stat here was ever generated after the game it's trying to predict.

Reading a pick

The percentage is the favored team's chance to win, based on the stat gap between the two teams' most recently completed seasons plus a standard home-field bump. It is not a point-spread or a score prediction — just a probability.

Methodology

Where this data comes from

Every number on this page comes from real NFL play-by-play and schedule data, pulled with nfl_data_py (which wraps the open nflverse data project). The league table shows each team's actual most recent completed season. The model was trained on eleven years of history: every team's completed season, from 2015 through 2024, paired with the games that team played the following year.

The schedule at the top of the page is live — this file has no database of its own. Every time you load the page, it fetches the current NFL schedule directly from nflverse in your browser, figures out which week is in progress (or up next), and checks every past game in the season for a final score. That's also how the season record stays current with zero maintenance: once a game finishes and nflverse publishes the score, this page picks it up on the next load.

The model's weights and each team's season stats are trained offline and baked into this file — retraining isn't something a browser should do on every visit. To refresh those with a new season: rerun python nfl_data_pipeline.py then python train_real_model.py, and drop the resulting model_export_real.json into the MODEL object in this page's script. The live schedule and season record need no such update — they track the real NFL calendar automatically.

The Kalshi market column pulls live, real-money odds for the Kalshi "NFL Game Winner" markets (series KXNFLGAME) straight from Kalshi's public API, and shows whether the crowd's money agrees or diverges from this model's pick. It's read-only — nothing on this page places or manages any trade. Since this file has no server of its own, that data is fetched directly from your browser; if Kalshi doesn't allow that for a page hosted elsewhere, the column will say so rather than show stale numbers.
